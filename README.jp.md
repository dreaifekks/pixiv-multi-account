# Pixiv アカウント切り替え

[English](README.md) · [中文](README.cn.md) · **日本語**

ログイン済みのアカウントを、Pixiv のプロフィールメニューからワンクリックで切り替え。

ログイン後にアカウントを自動で保存するので、手動の保存操作は不要です。次に Pixiv を開いたときは、使いたいアカウントを選んで閲覧や創作を続けられます。

## 主な機能

- **アカウントを自動保存**：Pixiv に通常どおりログインすると、一覧に追加されます。
- **2つの切り替え方法**：Pixiv のプロフィールメニューとブラウザーのツールバーから一覧を開けます。
- **サイトの言語に対応**：現在の Pixiv ページに合わせて、簡体字中国語・繁体字中国語・日本語・英語で表示します。
- **ローカル保存**：アカウント情報とログインセッションは現在のブラウザープロファイルに保存し、クラウド同期は行いません。

## 使い方

1. Pixiv にログインし、プロフィールメニューを開くと現在のアカウントが表示されます。
2. 「アカウントを追加」をクリックし、新しく開いた Pixiv 公式ページで別のアカウントにログインします。
3. ログインが完了すると、新しいアカウントが自動で一覧に追加されます。
4. 一覧のアカウントをクリックすると切り替わります。使用中のアカウントには「現在」と表示されます。

追加を取り消すには「元のアカウントに戻る」をクリックします。ブラウザーのツールバーにある拡張機能アイコンからも一覧を開けます。

同じブラウザープロファイル内の Pixiv タブはログイン状態を共有し、切り替え後に Pixiv 本体のページがまとめて再読み込みされます。アカウントを順番に切り替えるための機能であり、タブごとに別のアカウントで同時ログインすることはできません。セッションの有効期限が切れた場合は、Pixiv で再ログインしてください。

## インストールと更新

**Chrome 124 以降**が必要です。シークレットモードには対応していません。

1. [Releases](https://github.com/dreaifekks/pixiv-multi-account/releases/latest) から `pixiv-multi-account-バージョン.zip` をダウンロードして展開します。
2. `chrome://extensions` を開き、「デベロッパー モード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、`manifest.json` が入っているフォルダーを選択します。
4. 開いている Pixiv ページを再読み込みします。

更新時は、最初に読み込んだフォルダーのファイルを新版で上書きし、拡張機能の管理画面で再読み込みした後、Pixiv を再読み込みしてください。同じフォルダーと拡張機能を使い続ければ、保存したアカウントは保持されます。アンインストールは不要です。Chrome に Pixiv へのアクセス許可を求められた場合は、許可してください。

## 表示言語

現在の Pixiv ページの言語を優先します。取得できない場合は、URL の言語指定、ブラウザーの言語の順に判定します。ページの言語が変わると、メニューと切り替え中のメッセージも更新されます。

ツールバーポップアップは、開いた時点の Pixiv タブの言語を読み取ります。他のサイトで開いた場合はブラウザーの言語を使います。簡体字中国語と繁体字中国語には、それぞれ専用の翻訳を使用します。未対応のサイト言語では英語を表示します。

## プライバシーと権限

アカウントの表示と切り替えのため、アカウント ID、表示名、アバター URL、ログインセッションをローカルに保存します。パスワードの読み取り・保存、アクセス解析、開発者のサーバーへのデータ送信は行いません。アカウントの確認では Pixiv に直接接続し、アバターは Pixiv の画像サーバーから読み込みます。

| 権限 | 用途 |
| --- | --- |
| `cookies` | Pixiv のログイン Cookie を読み取り・復元して、アカウントを切り替えます。 |
| `storage` | アカウント、セッション、操作失敗時の復旧用記録をローカルに保存します。 |
| Pixiv へのサイトアクセス | ログインしているアカウントの確認、関連する Cookie へのアクセス、Pixiv 本体への切り替え UI の表示に使います。 |

サイトのアクセス権限は `pixiv.net`、`www.pixiv.net`、`accounts.pixiv.net` に限定しています。アカウント確認の通信、ログインページ、Cookie の書き戻しには HTTPS を使用します。

個人が開発する非公式の拡張機能であり、Pixiv とは関係ありません。

## お問い合わせ

アカウント一覧が更新されない場合は「更新」をクリックしてください。拡張機能の更新後に切り替えができない場合は、開いているすべての Pixiv ページを再読み込みしてからお試しください。

その他の不具合は [GitHub Issues](https://github.com/dreaifekks/pixiv-multi-account/issues) からお知らせください。Chrome と拡張機能のバージョン、ページの言語、再現手順を添えてください。Cookie やログインセッションの値は投稿しないでください。

## 開発

Chrome Manifest V3 を使用し、コンパイル工程や実行時の依存パッケージはありません。テストとパッケージ作成には Node.js 24 と npm が必要です。

```sh
npm ci
npm test
npm run package
```

出力先は `dist/pixiv-multi-account-バージョン.zip` です。`manifest.json` と `package.json` のバージョンは一致している必要があります。`fflate` はパッケージ作成にのみ使用し、拡張機能には含まれません。リソース用のサブディレクトリを追加する際は、`scripts/package.mjs` も更新してください。

`v0.3.2` のようにバージョンと一致する `v*` タグをプッシュすると、テスト、パッケージ作成、GitHub Release の公開を実行します。通常のブランチへのプッシュではパッケージを作成しません。

自動テストは、アカウントの認識・追加、切り替えとロールバック、権限確認、言語判定を対象としています。`tests/preview.html` では架空のアカウントを使い、言語、ライト・ダークテーマ、パネル幅を変更して動作を確認できます。
