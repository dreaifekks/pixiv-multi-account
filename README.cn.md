# Pixiv 账号切换

[English](README.md) · **中文** · [日本語](README.jp.md)

在 Pixiv 头像菜单里，一键切换已登录过的账号。

登录后自动记住账号，无需手动保存。下次打开 Pixiv，直接选择想用的账号，继续浏览或创作。

## 功能

- **自动记住账号**：在 Pixiv 正常登录后，账号自动加入列表。
- **两个切换入口**：从 Pixiv 头像菜单或浏览器工具栏打开账号列表。
- **跟随网站语言**：支持简体中文、繁体中文、日语和英语，随当前 Pixiv 页面的语言显示。
- **本地保存**：账号资料和登录会话保存在当前浏览器配置文件中，不使用云同步。

## 使用方法

1. 在 Pixiv 正常登录，打开头像菜单即可看到当前账号。
2. 点击“添加账号”，在新打开的 Pixiv 官方页面登录另一个账号。
3. 登录完成后，新账号会自动加入列表。
4. 点击列表中的账号进行切换；正在使用的账号旁会显示“当前”。

添加过程中可以点击“返回原账号”取消。也可以通过浏览器工具栏中的扩展图标打开账号列表。

同一浏览器配置文件中的 Pixiv 标签页共用登录状态，切换后已打开的 Pixiv 主站页面会一起刷新。此扩展用于轮流切换账号，不支持在不同标签页同时登录不同账号。登录状态过期时，需要在 Pixiv 重新登录。

## 安装与更新

需要 **Chrome 124 或更高版本**。不支持无痕模式。

1. 从 [Releases](https://github.com/dreaifekks/pixiv-multi-account/releases/latest) 下载 `pixiv-multi-account-版本号.zip` 并解压。
2. 打开 `chrome://extensions`，启用“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的目录。
4. 刷新已打开的 Pixiv 页面。

更新时，将新版文件覆盖到原加载目录，在扩展管理页点击“重新加载”，再刷新 Pixiv。沿用原目录和原扩展即可保留账号记录，无需卸载。如果 Chrome 提示允许 Pixiv 站点访问，请完成授权。

## 界面语言

扩展优先跟随当前 Pixiv 页面的语言；未能获取时，依次使用网址中的语言标识和浏览器语言。页面语言变化时，菜单和切换提示也会更新。

工具栏弹窗在打开时读取当前 Pixiv 标签页的语言；在其他网站打开时使用浏览器语言。简体和繁体中文分别使用对应文案，未支持的网站语言使用英语。

## 隐私与权限

扩展在本地保存账号 ID、昵称、头像地址及登录会话，以显示列表和切换账号。不读取或保存密码，不使用分析统计，也不向开发者服务器上传数据。账号核验直接访问 Pixiv，头像从 Pixiv 图片服务器加载。

| 权限 | 用途 |
| --- | --- |
| `cookies` | 读取和恢复 Pixiv 登录 Cookie，完成账号切换。 |
| `storage` | 在本地保存账号、会话及操作失败时的恢复记录。 |
| Pixiv 站点访问 | 核验登录身份、访问相关 Cookie，并在 Pixiv 主站显示切换界面。 |

站点权限仅涵盖 `pixiv.net`、`www.pixiv.net` 和 `accounts.pixiv.net`。账号核验请求、登录页和 Cookie 写回使用 HTTPS。

这是独立开发的非官方扩展，与 Pixiv 无隶属关系。

## 问题反馈

如果账号列表未更新，可点击“刷新”。更新扩展后无法切换时，请先刷新所有已打开的 Pixiv 页面再试。

其他问题请通过 [GitHub Issues](https://github.com/dreaifekks/pixiv-multi-account/issues) 反馈，附上 Chrome 版本、扩展版本、页面语言和复现步骤。请勿附带 Cookie 或登录会话值。

## 开发

使用 Chrome Manifest V3，没有编译步骤或运行时依赖。测试和打包需要 Node.js 24 与 npm：

```sh
npm ci
npm test
npm run package
```

安装包输出到 `dist/pixiv-multi-account-版本号.zip`。`manifest.json` 与 `package.json` 中的版本号须一致。`fflate` 仅用于打包，不随扩展发布。新增资源子目录时，需同步更新 `scripts/package.mjs`。

推送与版本号一致的 `v*` 标签（例如 `v0.3.2`）会触发测试、打包和 GitHub Release 发布。普通分支推送不会触发打包。

自动化测试覆盖账号识别、添加、切换与回滚、权限检查及语言识别。`tests/preview.html` 提供合成账号演示，可切换语言、明暗主题和面板宽度。
